1 · Data drift

Current window vs reference
FeaturePSIKS stat Reference meanCurrent meanStatus

Flagged when PSI > 0.20 or KS stat > 0.10. Both are effect sizes. The KS p‑value is deliberately not used: at these sample sizes it rejects on any negligible difference, so a p‑value rule would flag every feature every window. The two measures are complementary — on a feature whose reference mass sits almost entirely at zero, the decile bins collapse and PSI goes blind, but KS still sees the shift.

2 · Performance over time

Rolling windows at threshold
Recall Precision PR-AUC dashed = trigger floor (recall 0.90, precision 0.20)

The monitored period is the last 7,200 transactions, split into 12 equal windows and re-scored at the deployed threshold as the feed advances. Triggers take the worst window in that period, so an incident keeps the alarm up until it ages out of the retained history — about 80 ticks, or roughly 72 seconds of feed. Reset clears it immediately.

What is real here. The scoring is the real deployed model — the same 300-tree XGBoost Base ensemble evaluated in your browser — and the monitoring maths is a direct port of monitoring/monitoring_core.py, checked against the Python to 1×10−9 by tests/test_web_monitoring_parity.py.

What is simulated. The feed itself. PaySim is a fixed dataset with no live stream, and confirmed-fraud labels would in reality arrive days-to-weeks later via chargebacks, so precision and recall could not be computed this promptly in production. Transactions are generated PaySim-shaped — legit balances reconcile; fraud drains the origin account into a destination that never credits it, leaving errorBalanceDest equal to the amount. The fraud rate is held at 1% across both regimes, above PaySim's post-filter 0.296%, so the rolling windows collect enough positives to read in seconds. The degraded regime raises amounts and stops the destination ledger reconciling on ordinary traffic — the same footprint the model learnt to treat as fraud, which is why precision collapses while recall holds.
